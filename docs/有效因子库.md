## 权威文件

- `factor_library/library.json`：程序读取的唯一当前库；
- `factor_library/current.csv`：由JSON导出的人工作业视图；
- `runs/factor_validation/<run_id>/`：不可变完整检验证据。

每条有效记录包含因子名、稳定的`family/category`、`input_bar_frequency`、
`signal_frequency`、单一`best_period`证据标签、方向、IC/t/q、研究窗口、入库日期和证据哈希。
相关聚类的`cluster_id`随样本、阈值和算法变化，只保存在
`runs/factor_selection/<run_id>/`，不得写成因子的永久属性。

## 日常操作

在IDE打开根目录`run_factor_workflow.py`：

1. 默认`VALIDATE_FACTOR_BATCH`：填写本次完整`FACTOR_NAMES`后运行；
2. 首次建库或重建时显式选择`VALIDATE_ALL_INTRADAY`；
3. 审阅正式run后选择`ADMIT_COMPLETED_RUN`入库；
4. 需要相关聚类及组合候选时选择`SELECT_EFFECTIVE_SUBSETS`。该流程按固定生产配方生成
   多路径、多规模的`portfolio_candidates`；`recommended_core`只兼容展示首项，
   不把历史6/8/10/13因子数当作模板，也不自动批准生产组合。

共同周期和单切分观察run不可入库。入库不会修改策略、目标权重或生产批准。完整门槛与
防混用规则以`docs/因子检验与准入流程.md`为准。
