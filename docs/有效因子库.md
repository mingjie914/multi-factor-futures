## 因子库更新流程

1. 新因子通过研究检验 (`research --multi-period`) + 相关性门槛 (|corr|<0.5, `--corr-threshold 0.5`)
2. 加入**候选池** (更新本文档第二层)
3. 通过组合回测验证 (夏普不降) → 升级到**组合因子** (更新 `strategies/combined.py::FACTORS`)
4. 运行 `python scripts/export_factor_library.py` 同步
