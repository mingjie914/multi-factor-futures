## 更新规则

1. 新因子先注册到发现池，再按 `docs/因子检验与准入流程.md` 执行正式检验。
2. 入池审查显式使用`|corr| >= 0.5`的冗余门槛，并人工复核聚类经济含义。
3. 修改 `validated_candidates` 时同步本文；修改生产因子只能通过人工决策更新
   `strategies/combined.py`，不得由研究脚本自动写入。
4. 永久保留holdout ledger和可信不可变run；已被正确性错误否定的派生产物直接清理，
   并在`runs/README.md`登记原因，不能恢复成当前证据。
