# 交易成本与换手：统一口径、模块位置与验收

2026-09-13审阅。本文是通用口径说明，不是新的因子准入政策或策略配置。
默认费用仍读取`config/default.yaml::costs`，成员、方向、预测期和实盘发布状态不变。

用户最新提出的准入原则：有效库阶段不以换手淘汰统计有效因子；交易经济性在组合层
判断。本审阅赞同这一职责划分，但现有流程还有成本覆盖的间接筛选，尚未擅自删除。
若落实该原则，应显式更新准入合同、说明取消的是成本代理后置门而非放宽IC/t/FDR，
并复核受影响因子；不能一边更改实际筛选、一边宣称准入流程完全未变。

## 拓扑与唯一职责

```text
全部因子 → 冻结准入检验 → 有效库 → 组合构建/选择 → 目标权重
                                                   ↓
                 成本模型 → 原生回测账本：漂移/交易可行性/具体合约转换
                                                   ↓
                                  执行换手 → 扣费 → 净收益/净值
                                                   ↓
                     通用成本诊断 + 分段稳健性 → 报告/备选资格讨论
                                                   ↓ 显式请求
                                   成交校准/容量/执行仿真
```

- `optimization/costs.py`：现有成本模型负责收费规则；`evaluate_cost_sensitivity`
  是通用回测后诊断入口。复用现有模块，不新增策略专用脚本或第二套注册机制。
- `backtest/research_ledger.py`：实际生效权重、合约转换、归一化换手、费用及净值
  的逐日账本；`backtest/engine.py`共用转换与收益核算函数。统计不得另推一套成交。
- `backtest/metrics.py::compute_turnover_metrics`：只接收已执行持有区间的完整换手。
  调仓决策、目标权重差、信号排名变化不可冒充执行统计。
- 正常回测保存及生产配方入口默认输出`cost_diagnostics.json`；归因报告调用同一函数，
  按全期/截止前/观察段展示。输入为账本，不依赖策略名称、因子数或有效库身份。
- 费用必须在每个组合的回测内扣除后再比较，不能只对优胜者补扣；静态诊断计算量小，
  可统一运行。昂贵的成交与容量检验只在冻结候选后显式运行。
- 默认诊断方法为`static_turnover_rate_v1`，默认费率网格1/2/3/4/6/8bp；网格只是
  诊断假设，不覆盖2bp基线费用。函数允许显式传入其他费率；结果记录方法、费率、
  持有费处理与样本数量。其他收费模型沿用现有`costs.type`注册入口显式选择，
  不自动择优、更不按模拟实盘段表现切换模型。尚未实现的执行仿真不得声称可选可用。

## 基础核算定义

1. 目标权重W[T]用于T+1持有区间；当前是收盘到收盘的研究近似，不是临收盘订单
   的真实成交仿真。交易可行性和延期换月按现有数据门禁处理。
2. 基准是归一化净值，不要求人民币本金，不模拟保证金、整手、追加保证金或券商现金账。
   毛收益为生效权重乘资产收益之和，净收益＝毛收益－交易费－持有费。
3. 调仓前权重按价格和净收益漂移；完整换手＝具体合约目标权重与漂移权重绝对差之和。
   买卖、开平均累计，不除2。总敞口2已在权重中，不能再额外乘2。
4. 初始空仓建2倍敞口：换手2；平旧2再开新2：换手4。反向翻仓计平旧加开新。
   全期第一个净值点只是锚点，无前置持有收益；最后收盘目标不视为已执行，
   不默认强制清仓或收取尚未发生的退出费。强制期末清仓必须是显式情景。
5. `executed_traded_notional`与`turnover`均为归一化完整换手，不是金额；
   `half_turnover=0.5*turnover`只作兼容字段。年化＝252×全部持有日均值，含零成交日。
   `avg_turnover`保留历史的有成交日均值；`avg_daily_turnover`才用于年化，不能混用。
6. `executed_roll_turnover`是变更合约仓位的全部平开腿，包含同时发生的加减仓/反向。
   它属于完整换手子集，不能再加到总换手上收费，也不应称为固定数量的纯移仓增量。
   “纯维持方向的移仓量”若另做诊断可定义为同号仓位的2×min(旧绝对仓位,新绝对仓位)，
   但本次不改变已有换月字段定义和数值。
7. 截止后第一天的收益、费用、执行换手全部属于观察段；前一收盘只作净值锚点。
   历史分段不重置仓位、不重新收初始建仓费、不漏掉边界一天。
8. 费用字段是当日归一化收益扣减；简单求和不是复利净值损失或人民币费用。
   利润贡献使用前日净值链式加权，逐品种毛贡献加独立负费用须与区间净收益对账。
   历史`total_transaction_cost`字段有包含持有费的兼容含义，不能解释为纯手续费；
   明细对账使用`trade_cost`和`holding_cost`，不将摘要字段再次扣费。

## 已修正与不擅自改动的事项

| 项目 | 结论与处理 |
|---|---|
| 管理费误标 | 旧共享账本把持有费合计写入management_fee；改为真正管理费，另列roll_reserve_cost，合计恒等于holding_cost。总扣费与净值不变；schema升为7，旧账本按原schema理解。 |
| 分段漏算边界 | 比较入口与75/25诊断原丢弃后段首日；现在保留前一收盘作锚点，后段收益与换手完整纳入。分段指标需重绘，净值不变。 |
| 初始锚点混入指标 | 生产配方入口计算夏普/波动时剔除首个无持有区间锚点，与其他回测入口一致。 |
| 无交易数据显示零 | 比较报告改为不可得，不用缺失账本证明零换手。 |
| 双倍成本名称 | cost_multiplier仅放大交易费并重算漂移；static_cost_stress显式分别指定交易/持有乘数。原归因报告static_cost_2x仍代表两类费用均加倍的固定路径诊断，不冒称重放。 |
| 2bp与移仓预留 | 实际换月腿已按2bp收费，同时保留总敞口×年化10.5bp预留。代码没有把换月换手重复加进总换手，但预留经济含义缺乏实证拆分，可能与费率中包含的滑点重叠。本次不擅自取消费用。 |
| 准入成本代理 | 收益端为分层多空价差（多1空1），换手端为总敞口1的全截面秩权重，按best_period抽样；不是同一组合，也不包含具体合约换月/漂移。不能直接当实盘成本覆盖证明。保留冻结准入合同，另做同批因子对照后决定是否升级，不静默重写有效库。 |
| 可选多袖聚合 | 元组合计入子组合已有扣费，仅另扣元分配费用，并非再扣一份全部子组合费用。分袖交易量累计不等于跨袖净额成交；缺乏合约级净额订单时，不宣称已节省内部对冲交易费。旧纯净值叠加无完整执行路径时不补造换手。 |

建议最终费用政策：以实际成交手续费＋价差/冲击为交易成本主体，显式换月腿同样计费。
只有能证明尚未覆盖的额外移仓成本才保留独立预留。此前2bp是否含全部滑点、10.5bp
是否覆盖相同项目，不能靠代码判断；需要品种费表和成交校准。在证据齐备前，默认参数
不变，同时展示“保留预留”和“显式成交成本已覆盖、不再重复预留”的独立情景，不自动选低费用方案。

## 成本后的收益与稳健性评价

- 已实现：固定原账本路径，替换交易费率而非叠加一份新费用；持有费用保持原值。
  输出完整年换手、净年化/夏普/回撤、各情景和按复利收益为零求得的盈亏平衡费率。
  零交易、零交易费仍亏损、情景净值耗尽分别标识，不给虚假无穷承受力或通过结论。
- 接着对关键情景重放同一目标权重的原生账本，让扣费后的漂移重新计算；费用上升
  不得在固定路径测试中提高净值，重放与静态测试则不要求逐点相等。
- 沿冻结时间分段/年度/滚动252日比较净年化、夏普、最大回撤及修复时长、正收益比例、
  最差阶段和品种/板块贡献集中度。长历史诊断与准入短区间分开；2026-05-15之后
  已被查看的观察段不作为新锁箱，不据此反复更换成员或费用模型。
- 深层检验需显式资金规模、合约乘数、每手费及开平差异、执行时间窗口、价差与
  成交量：计算参与率、整手与容量、延期/未成交、保证金约束；缺数据就标未验证。
- 不设未经批准的新硬门。候选应在现实成本加预先声明的安全余量后仍有收益，
  且不是靠少数时段/板块支撑；回撤及承受成本须符合事先风险预算。
  单看2倍费用夏普为正，不能自动批准实盘。

## 单因子统计：同一模块的不同输入

准入代理诊断保留且明确标识，不作为策略表的单因子换手列。正式策略诊断先覆盖
当前10组的28个不同成员，每个成员只计算一次（冻结方向不同则分开）：

1. 以原bar计算因子、输出日频，固定原方向；best_period不指定调仓频率。
2. 将单因子视为一组信号，复用同一选品种、cap、ERC、总敞口及交易可行性流程；
   单个因子的合成权重为1，不制造跨因子IC协方差估计。标签明确为独立单因子组合。
3. 同日期、预热、数据指纹与费用，经原生账本输出完整年换手、换月成交分量、
   有效/不可交易天数及成本压力；不能把平均信号变化率冒充成交换手。
4. 多因子组合的边际换手＝完整组合－删除该因子的组合；两边必须同数据重新计算，
   保留品种选择等非线性环节。正负皆可，不能求和作为交易费分摊。
5. 输出共用诊断结果并按成员映射进入报告，不创建28份脚本，不改变策略成员。
   本次完成方案与通用入口，不宣称已完成28个独立组合和逐一删除的新增回测。

## 验收边界

实测覆盖完整/半换手、零成交日、杠杆不重复、合约切换、延期换月、最后目标不计成交、
费用组成、固定路径成本单调、费率替换基线复现、盈亏平衡、分段连续性及缺失不可伪造。
修复前后合成账本120日逐点对照（含换月、管理费0/1%）：除修正字段外，原有数值字段、
有效权重、收益和净值完全一致。分段及首锚点修正只改变相应统计展示，不改变净值。
当前10组已重算至2026-09-11；原区间净值逐点一致，日收益最大浮点差2.61e-18。
本次新账本管理费字段按schema7校正，费用总额、收益及净值不变，记录于源目录
accounting_review.json；旧不可变研究证据不修改。
全套回归903项通过。另对当前10组的冻结历史原生账本实测：2bp情景复现基线，
逐日交易费＝完整换手×2bp，毛收益减交易费及持有费＝净收益；不是最新日期重算结果。
