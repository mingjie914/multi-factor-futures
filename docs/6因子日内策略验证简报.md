## 交易周期说明

| 维度 | 说明 |
|------|------|
| 数据频率 | **1分钟 bar**（从本地 Parquet 读取 240 根/天） |
| 因子计算 | 每日对全天分钟数据做统计 → 日频信号值 |
| 滚动窗口 | 20 个交易日 |
| 信号频率 | **日频**（每天产出 1 个信号值） |
| 持有周期 | 20 个交易日（约 1 个自然月） |
| 调仓频率 | **周度**（holding_period=5天） |
| 本质 | 用微观结构（分钟数据）预测中短期方向，**非每分钟调仓的高频策略** |

## 三、Phase 1 影子运行配置

### 已就绪

配置文件 `config/intraday_backtest.yaml` 中已包含 6 个因子：

```yaml
factors:
  - intraday_jump_intensity_20d
  - intraday_price_peak_count_20d
  - intraday_realised_skewness_20d
  - intraday_dtws_20d
  - intraday_drip_stone_20d
  - intraday_peak_ridge_ratio_20d
```

### 日常运行命令

```powershell
# 更新数据后跑回测
python main.py backtest --config config/intraday_backtest.yaml

# 研究模式
python main.py research --config config/intraday_backtest.yaml --all --multi-period

# 因子挖掘冒烟测试
python main.py mining dev-smoke --config config/intraday_backtest.yaml
```

### 当前不操作
- `config/default.yaml` 中 `factors: []` 保持不变
- `config/trading.yaml` 保持关闭
- 所有因子仅通过 `intraday_backtest.yaml` 在研究模式下运行
