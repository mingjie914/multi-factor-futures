## 关键结论 (固化依据)

1. **品种池**: manual29 (流动性适中、数据完整) 远优于 all61, 全量与 OOS 双优
2. **因子集**: 6因子 (第一批) OOS 0.92 ≫ 11因子 0.61, 新增5因子是噪声源, **弃用**
3. **权重**: 池内纯风险平价 (rp) 优于等权/半风险平价
4. **调仓**: 周度最优 (0.93 vs 日度0.84/月度0.92)
5. **换手**: 6因子+manual29+rp 月换手 18%, 摩擦成本可控
