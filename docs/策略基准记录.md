## 编号规则

- `A`：当前主观察分支。以后需要并列登记的主分支均以 `A` 开头。
- `B*`：复用框架数据、因子或组合组件的多品种变种，不修改主生产流程。
- `6f`、`8f`、`10f`、`13f` 等是因子集名称，不是分支编号。
- 目录和模块继续使用可读的业务名称；分支编号记录在本登记和分支配置元数据中，避免
  为编号变化重命名稳定的 Python 导入路径。

## 变种 B1：国信趋势指数形式代理

| 项 | 值 |
|---|---|
| 品种池 | AU、CU、IF、IC、RB、SC、M、TF、T |
| 方向/调仓 | 仅做多 / 日度 |
| 选取 | 每个“因子×参数”独立保留前51%，九个品种即取五个 |
| 合成 | 先平均同一因子的参数组合，再等权平均不同因子组合 |
| 品种权重 | 4%目标波动率、相关性修正逆波动率及单品种上限 |
| 最终持仓 | 不强行补仓；不同因子入选集合合成后应覆盖九个多头品种 |
| 成本 | 0.02%交易成本、年化0.1%费用 |
| 实现/配置 | `external_strategies/guosen_trend_index/` / `config.yaml` |
| 状态 | 独立影子对照；主框架和生产策略不导入该适配器 |

公开说明未披露原指数的真实因子、参数和全部风险窗口，因此 B1 是可审计的形式代理，
不是 `GSIXTREND.WI` 的精确复制。6f、8f、10f、13f等替换因子集可以在 B1 结构下独立
比较；其表现随因子集和敞口口径变化，不登记一个脱离口径的固定夏普值。
