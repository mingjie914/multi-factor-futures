## 第一部分: 中金研报《日内量价信息驱动下的CTA交易策略》

### 1. 底层输入 (1分钟主连)

$$X_{i,t} = (O_{i,t}, H_{i,t}, L_{i,t}, C_{i,t}, V_{i,t}, OI_{i,t}, A_{i,t})$$

$O/H/L/C$=开高低收, $V$=成交量, $OI$=持仓量, $A$=成交额

### 2. 因子体系: 207 个价量特征 (四类)

| 因子组 | 工程含义 | 典型构造 |
|---|---|---|
| 方向趋势 | 价格方向/速度/趋势强弱 | MA, EMA, MACD, ROC, AROON, 线性回归斜率 |
| 波动振幅 | 振幅/价格边界/极端波动 | ATR, 布林带宽, 滚动标准差, CHLLC震荡, 双向波幅 |
| 资金成交 | 成交量/额与价格方向 | MFI, OBV, 量价相关, 成交额非线性变换 |
| 统计结构 | 数学变换生成新结构 | OHLC合成价, 滚动相关, 集中度, 累积, 非线性变换 |

### 3. 未来收益标签 (预测视窗 h)

时序线 (h=30分钟): $y^{(h)}_{i,t} = \log(P_{i,t+h}/P_{i,t})$
截面线 (h=日度): 下一交易日开盘到收盘收益

### 4. 信息系数 IC (单因子排序能力检验)

$$\mathrm{IC}^{(h)}_{f,t} = \mathrm{corr}_{i\in\Omega_t}(f_{i,t}, r_{i,t\to t+h})$$

工程上关注 $|\mathrm{IC}|$ (可反号转正向信号)

### 5. 高低波分域 (核心工程点)

20日已实现波动率: $RV^{(20)}_{i,t} = \sqrt{252}\cdot\mathrm{Std}(r^{(1)}_{i,t-240},...,r^{(1)}_{i,t-1})$
240日滚动75%分位阈值: $q^{75}_{i,t} = Q_{75\%}(RV^{(20)}_{i,t-240},...,RV^{(20)}_{i,t-1})$
状态标签: $D_{i,t} = 1$ (高波) if $RV > q^{75}$, else 0
分域目标缩放: $z^{(h)}_{i,t} = y^{(h)}_{i,t}/\hat{\sigma}_{i,D_{i,t}}$

**高波/低波 IC 倍率**: 方向趋势 2.0x, 波动振幅 2.9x, 资金成交 3.7x, 统计结构 2.4x

### 6. 时序预测模型 (阈值交易)

扩展窗口标准化: $z^{(f)}_{i,t} = (x^{(f)}_{i,t}-\mu_{i,1:t-1})/\sigma_{i,1:t-1}$ (无未来函数)
分域 LGBM 训练 → 阈值过滤: $p_{i,t} = +1/-1/0$ by $|\hat{y}|$ vs $\theta_t$
净收益: $R^{net}_{i,t+1} = p_{i,t}r_{i,t+1} - (c_{bp}/10000)|p_{i,t}-p_{i,t-1}|$

### 7. 截面多空 (Top/Bottom 20%, 美元中性)

复合 alpha: $\alpha_{i,t} = \frac{1}{M}\sum_k z_k(f_{i,k,t})$
权重: $w_{i,t} = +1/(2N_L)$ Top20% / $-1/(2N_S)$ Bottom20% / 0
约束: $\sum w=0$, $\sum_{w>0}w=0.5$, $\sum_{w<0}|w|=0.5$
净收益: $R^{net}_{t+1} = \sum_i w_{i,t}r_{i,t+1} - (c_{bp}/10000)\sum_i|w_{i,t}-w_{i,t-1}|$

### 8. MOSEK 组合优化

目标: $\max_w\; w^\top\alpha - \frac{\lambda}{2}w^\top\Sigma w$
Ledoit-Wolf: $\hat\Sigma = (1-\delta)S + \delta F$
约束: $\sum w=0$, $w^\top(252\hat\Sigma)w \le 10\%^2$, $\|w-w_{prev}\|_1 \le 30\%$, $|w_i| \le 2.0$

### 9. 滚动 IC 选因子

滚动IC均值: $\overline{IC}^{(W)}_{m,t} = \frac{1}{W}\sum_{k=1}^{W}IC_{m,t-k}$
每周选前10% → 当周因子池 → 复合 → MOSEK。窗口 40 周最优

## 第二部分: 《因子库精简与优化实践》(100因子 → 12因子, 夏普2.8)

### 1. 四大问题: 信息重叠/过拟合/参数灾难(K≈T)/维护成本

### 2. 正交化增量筛选
候选因子对已选因子回归取残差 → 残差做 Fama-MacBeth → 显著且R²提升最大者纳入

### 3. Fama-MacBeth 回归
每期截面回归: $R_t = \alpha + \beta f_{t-1} + \epsilon$; $t_{stat} = \bar\lambda/(std(\lambda)/\sqrt{T})$

### 4. 最大化 IC_IR 权重 (解析最优)
Spearman IC 矩阵 → Ledoit-Wolf 收缩 → $w^* = \hat\Sigma^{-1}_{IC}\cdot\overline{IC}$, 归一化 $|w|_1=1$

### 5. Ledoit-Wolf 收缩
$\hat\Sigma_{shrink} = \lambda F + (1-\lambda)\hat\Sigma_{sample}$, 最优$\lambda$由 pi/rho/gamma 计算

### 6. Bootstrap 权重平滑
IC 序列重抽样 → 每次算权重 → 平均 → 平滑极端值

### 7. 因子预处理
3σ缩尾 + z-score: $x' = (clip(x,\mu\pm3\sigma)-\mu)/\sigma$
