## 1. 目标

1. **因子运营监控(A)**:像产品运营一样跟踪每个因子,产出滚动 IC、胜率、回撤-反弹周期、健康状态机,支撑"生产批准 / 剔除 / 再激活"决策(当前 `validation_funnel.json` 中 `production_approved: 0` 无证据链)。
2. **组合收益归因(B)**:收益分解到因子 / 板块 / 品种,知道谁在赚钱谁在拖累,支撑动态调权。
3. **产出**:JSON(日度数据)+ PNG(图表)+ Markdown(周报),统一输出到 `weeklyreport/`。

## 2. 已确认的参数(与检验流程一致,不比检验更严格)

| 参数 | 值 | 依据 |
|---|---|---|
| IC 阈值(失效线) | **0.02**(与 `testing/ic_test.py` 准入门槛一致) | 用户:观察期不应比检验器更严格 |
| IC 判定窗口 | 连续 **20 日** < 0.02 → RETIRED(沿用 `alpha/ic_monitor.py` 现有逻辑) | 现有 ICMonitor 一致 |
| 回撤深度阈值 | **30%**(多空累计收益相对峰值回撤) | 用户原定,主流区间 20–30% |
| 回撤观察窗口 | **20 日** | 用户原定,行业常用 20–60 日 |
| 反弹确认 | **创 20 日滚动最高**(去抖:新高后维持 2 日) | 用户原定(创新高)+ 去抖 |
| 胜率维度 | 监控**报告**输出周/月胜率(观察指标,**不做状态机门槛**) | 不比检验更严,只展示 |
| 监控频率 | **日度计算落盘 + 周报展示**(周报含上周/本月/YTD 三口径) | 用户:周报与日度都要;日度计算必要、日度报告噪音大 |
| 产出目录 | `weeklyreport/`(独立文件夹) | 用户指定 |

### 4.2 `factor_health.py` — 因子状态机(A)

**状态**:`ACTIVE`(正常)/ `WATCH`(预警)/ `RETIRED`(失效,可再激活)

**数据流**(日度):
```
因子信号面板(从 runs/ 或 factors/engine 提取)
  → 逐日滚动 IC(60 日, 复用 ICTest / 向量化 Pearson)
  → 连续 20 日 < 0.02 → RETIRED; 回撤 > 30%(20 日窗口) → WATCH
  → 创 20 日新高且维持 2 日 → 恢复 ACTIVE(再激活)
  → 状态迁移写入 factor_health.json(含变更日志)
```

**4 口径指标**(周报展示):全样本 / 60 日 / 20 日 / 上周,每口径输出:
- IC、ICIR、HAC t(`ICTest` 既有)
- 多空收益、多头超额(做多前 N 名品种相对截面等权基准)
- 绝对收益 vs 超额收益分离度(诊断 beta 型 / alpha 型失效)
- 周/月胜率(展示)
- 4 周多空收益动量(因子择时观察指标,对应研报"回撤→反弹"周期)

**回撤-反弹周期**:对因子累计多空收益序列做滚动峰谷检测 → 输出 `{peak_date, trough_date, drawdown_depth, rebound_date, state}`。

**接口**:
```python
class FactorHealthMonitor:
    def __init__(self, config: MonitorConfig): ...
    def update(self, daily_ic: dict[str, pd.Series], signal_panel: pd.DataFrame, returns: pd.DataFrame) -> None:
        """日度增量: 更新滚动 IC/回撤/状态机, 落盘 monitoring/factor_health.json"""
    def get_state(self, factor: str) -> str: ...
    def health_snapshot(self) -> dict: ...      # 全因子健康快照(供周报)
```

### 4.3 `attribution.py` — 组合收益归因(B)

**数据源**:`ResearchReturnLedger`(`contributions = weights × returns` 已是逐日逐品种)。

**三层分解**(周报三口径:上周/本月/YTD):
1. **因子层**:因子权重 × 因子收益 → 各因子贡献(正/负排序,输出"谁在赚钱谁在拖累")。
   - 注:当前生产权重是 `combined.py` 6 因子 IC_IR 加权;因子层归因以"信号组合权重 × 品种收益"按因子分组聚合(与 `scripts/exp14_2024_contrib.py` 同思路,但做成正式模块)。
2. **板块层**:品种 → 板块映射(`combined.SECTOR`)聚合持仓收益 → 板块贡献表(对齐 021/022 CTA 周报"多能源化工、空黑色"式归因)。
3. **品种层**:逐品种明细(遵守持仓展示规则:上多下空、逐行完整)。

**接口**:
```python
class AttributionReport:
    def __init__(self, ledger: ResearchReturnLedger, sector_map: dict[str, list[str]], factor_map: dict[str, list[str]]): ...
    def factor_contribution(self, start, end) -> pd.DataFrame: ...   # 因子×贡献
    def sector_contribution(self, start, end) -> pd.DataFrame: ...   # 板块×贡献(多空分行)
    def asset_contribution(self, start, end) -> pd.DataFrame: ...    # 品种明细(上多下空)
    def to_json(self) -> dict: ...                                   # 供周报
```

### 4.4 `weekly_report.py` — 周报三件套

输出到 `weeklyreport/周报_YYYYMMDD/`:
- `周报_YYYYMMDD.md`:三口径表格(因子健康表 / 归因表)+ 状态迁移摘要 + 结论
- `因子IC热力图.png`(因子 × 时间 IC)、`因子回撤路径.png`(累计多空收益+回撤区间)、`归因贡献.png`(因子/板块贡献柱状图,多空分行)
- `snapshot.json`:当周快照(数据版,供程序消费)

## 8. 已确认的决策(2026-08 定稿)

| 开放项 | 决策 |
|---|---|
| 因子层"因子收益"定义 | **信号组合收益**:按因子值前 N 名多头 / 后 N 名空头的品种收益分组聚合(接近真实可交易收益);不用日度 IC 代理 |
| 回撤口径 | 主口径**多空累计收益**(与研报一致);**保留纯多头接口**(`multi_only: bool` 参数),后续开发纯多头策略时按策略自动启用 |
| 周报触发 | **手动触发** `scripts/run_monitoring.py report`(不挂定时任务,灵活随时生成) |

## 9. 实施注记(2026-08, 与设计稿的落地差异)

| 项 | 设计稿 | 落地实现 |
|---|---|---|
| 数据目录 | `monitoring/` | **`monitoring_data/`**(避免与 `monitoring/` 包目录同名混淆);周报目录 `weeklyreport/` 不变 |
| 板块映射 | `combined.SECTOR` | **`diag_production_nav.SECTORS`**(5 板块 + 归因自动追加"其他"未映射品种,保证对账完整) |
| 回撤口径 | 20 日窗口峰值 | **全历史峰值**(`nav/nav.cummax()-1`);DD_WINDOW 废弃——20 日窗口峰值在组合整体亏损时产生 -1000% 级伪回撤,已改用行业标准定义 |
| 状态机再激活 | 创新高即恢复 | **RETIRED 再激活需 IC 已回升**(`IC_REACTIVATE_DAYS=5` 最近滚动 IC ≥ 0.02),避免收益创新高触发 RETIRED↔ACTIVE 抖动 |
| 信号构建窗口 | `DATA_END=2026-07-31` 硬编码 | **运行时动态截断到数据源最后交易日**(`get_calendar(start, 2100) → cal_all[-1]`),并加缓存占位防御(>5000 日或 2100 年 → 告警退出) |
| 归因对账 | 板块层求和 | 板块多/空分列求和 + "其他"板块,与 `research_return_contributions.csv` 总贡献对账(实测 1e-6 内一致) |
