# 因子监控与归因仪表盘

> 状态：已实施，手动运行；更新于 2026-08-17。该模块只观察，不修改固定基线因子、
> 组合参数或目标权重发布批准门。

## 边界

- 代码位于 `monitoring/`，入口为 `scripts/run_monitoring.py`。
- 38品种池读取`core.sectors.FRAMEWORK_UNIVERSE`；固定观察因子和组合板块映射读取
  `strategies/combined.py`。策略中的`UNIVERSE38`仅是兼容别名，不维护第二份字面量。
- 可再生产物写入被 Git 忽略的 `monitoring_data/` 和 `weeklyreport/`。
- `config/target_publication.yaml` 保持关闭；健康状态不会自动增删因子、发布目标权重或触发外部下单。

## 监控口径

| 项目 | 当前值 |
|---|---|
| 状态 | `ACTIVE / WATCH / RETIRED` |
| IC 失效线 | 0.02 |
| 连续低 IC | 20 日 |
| 主/快滚动窗口 | 60 / 20 日 |
| 回撤阈值 | 相对全历史峰值 30% |
| 反弹确认 | 20 日新高维持 2 日 |
| 再激活 | 最近 5 日滚动 IC 回到阈值以上 |

阈值集中定义在 `monitoring/config.py`。当前观察基线为10f；以后人工变更基线因子时监控会
随 `strategies.combined.FACTORS` 自动同步。

该模块只监控旧10f观察基线，代码常量使用`OBSERVATION_*`命名；它不决定
`strategy_library.yaml`中的`preferred/observing`状态。平行策略的持续比较由
`run_portfolio_workflow.py`统一重跑到最新完整日期并保存多曲线结果。

## 归因与输出

- 因子层：方向化信号T的Top10减Bottom10等权收益对齐下一交易日T+1；IC为截面
  信号排名与T+1收益排名的相关系数。
- 板块/品种层：只读取调用方显式传入的ResearchReturnLedger目录中的有效权重、品种
  收益和贡献，不按修改时间自动选择“最近”账本；缺少ledger时仍可生成因子健康报告。
- 报告口径：上周、本月、年初至今。
- 每份周报包含 Markdown、JSON、IC 热力图、回撤图和可用时的归因图。

## 使用

```powershell
$PY = 'E:\Python\Pythonvenv\Scripts\python.exe'

& $PY -m scripts.run_monitoring build-signals
& $PY -m scripts.run_monitoring update
& $PY -m scripts.run_monitoring report          # 使用健康快照截至日
& $PY -m scripts.run_monitoring report 20260814 # 显式报告标签
```

`build-signals` 会从 2025-01-01 起计算到数据源实际最后交易日。若数据源返回空日历、
超过 5,000 日的占位日历或 2100 年日期，会失败关闭而不是生成伪结果。

## 验证与维护

- `monitoring_data/` 与 `weeklyreport/` 可随时重建，不属于长期研究证据；正式组合证据
  仍由不可变 run bundle 和 holdout ledger 管理。
