## 二、概念澄清 (重要)

### 2.1 IC_IR(LW) vs ICIR 最优 — 我们用哪个?

| 名称 | 公式 | 区别 |
|------|------|------|
| ICIR 最优 (经典) | `w* = Σ⁻¹·mean(IC)`, Σ=样本协方差 | 样本少时协方差病态 |
| **IC_IR(LW) (我们用的)** | `w* = Σ⁻¹·mean(IC)`, Σ=**Ledoit-Wolf 收缩** | 加收缩稳定, 小样本不炸 |

**固定观察结构使用 IC_IR(LW)**：60 日滚动 IC → LW 收缩协方差
（`λ·F + (1-λ)·S`，λ 由 pi/gamma 自动估计）→ `w* = Σ⁻¹·mean(IC)` →
取 `|w|` 归一化。ICIR 最优是 LW 的 λ=0 特例。

### 2.2 IC_IR 窗口是什么?

**窗口参数为60（日度滚动）**：决策日 `T` 先排除 `IC[T]`，再从严格早于 `T` 的
记录中取最近最多60条完整IC观测 → mean(IC) + LW协方差 → 权重。少于30条完整观测
不启用信号；30至59条属于明确的预热估计，成熟后固定使用最近60条，且不会混入
`IC[T]`。

历史窗口敏感性研究比较了 10/20/30/60/90 日；当时 60 日表现最好，短窗口 OOS 不稳、长窗口响应较慢。该结论作为方法选择证据保留，当前实现与测试才是权威定义。

### 2.3 ERC = 风险平价吗? 特殊处理?

**是** — ERC (Equal Risk Contribution) 是 Risk Parity 的精确形式: **每个持仓对组合波动率的边际贡献相等**。

本框架 **4 项特殊处理**:
1. **协方差收缩**: 90 日历日收益协方差, `cov = 0.7·样本 + 0.3·对角` (防病态)
2. **权重硬限制**: 默认区间为每个单位总敞口袖套的 [0.005, 0.20]；ERC原始解通过
   有界单纯形投影后同时满足总和为1和最终上限。可用 `asset_max_overrides` 为具体品种
   单独设置上限；20%不是板块上限
3. **板块约束分层**: `sector_count_cap=3`限制每侧各板块入选数量；可选
   `sector_weight_caps`才限制每侧板块权重。未配置时不虚构板块20%限制
4. **失败关闭**: ERC、约束投影或风险历史不满足声明时抛错，不自动切换为另一种方法

### 2.4 两级权重的分工 (易混淆点)

| 层级 | 方法 | 作用 |
|------|------|------|
| **因子层** (10因子→1信号) | IC_IR(LW) 动态加权 | 因子间权重；当前 `lw_abs` 对 `Σ⁻¹mean(IC)` 取绝对值，并非简单按IC高低分配 |
| **品种层** (10多/10空→持仓) | ERC (分开做) | 品种间权重 (风险贡献相等) |

**选池后 ERC 粒度**: `_pool_weights(long_pool)` + `_pool_weights(short_pool)` **分开调用** —
10 多头单独 ERC (归一化+1), 10 空头单独 ERC (归一化-1), **不是 20 个一起**。

## 三、历史5min切换验证的适用边界 (2026-08-06)

| 验证项 | 结果 |
|--------|------|
| 数据覆盖 | 当时指定38品种、日期和数据快照的验证通过；不是所有日期与因子的全局保证 |
| 因子值 | 原6f在当时快照相对差0.00%；不外推为当前10f全部成员的跨频率证明 |
| 性能 | 当时一次性基准约8倍加速；机器、缓存、因子集和数据范围变化后必须重新测量 |
| 路由 | `_get_minute_panel`严格传递因子显式请求，1min/5min不互相替换 |

**频率控制 (防错配)**: 因子必须显式声明读取频率；`force_1min=True`仅是兼容入口。
- **drip_stone (FFT 频谱) 强制真 1min** (2026-08-06): 5min 下部分品种/日期覆盖缺口导致 NaN, 生产 signal 曾返回 0 持仓; force_1min 修复后 signal 恒 20 持仓 (7 日期链路验证通过)。
- 历史全量 53 因子覆盖率对比确认 NaN 率在 1min/5min 间一致（`drip_stone` 强制 1min）；一次性验证脚本已清理。

**多分片读取修复 (2026-08-06)**: `_read_local_raw` 改为 glob 读全部 `data_*.parquet` (原只读 data_0, 多分片月份如 2024-11 返回 None → 因子 2024 年 NaN)。

## 四、10f来源与当前边界

10f来源仍可追溯，但旧选择证据已被分钟根污染和组合口径不一致否定：

1. 10f是13f剔除`jump_intensity`、`dtws`和`seat_long_short_seat_ratio`后的严格子集；
2. 旧固定集合比较已失效；当前单因子重检不等于固定集合组合重建，暂不比较10f、8f与13f优劣；
3. 经济来源覆盖价格发现、收益分布、成交量频谱、期限结构和流动性，但经济分散不能
   代替有效绩效证据；
4. 三个固定因子集使用完全相同的生产结构，差异可以归因于因子集；
5. 10f保留为观察基线，不再称为已验证的生产替代方案。

8f与13f继续作为固定因子集对照；等权/Top12/无cap/逆波动率只作研究挑战方法。
