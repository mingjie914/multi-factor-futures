## 已实现的运行链路

`run_trading_workflow.py` 提供互不自动串联的权重、资金折算、差额计划、人工文件、
本地 paper 演练、Panda 快照/冻结预演/明确确认发送/回报核对命令。
默认引用组合目录唯一正式策略；正式身份不等同发布或下单授权。

- 权重产物冻结策略版本、具体合约、数据/代码指纹及逐实例持仓状态；重复输入不改文件。
- 多策略与多账户由路由表连接。同账户同合约先合并名义目标，再对称四舍五入。
- 换策略/换版本保持账户连续性；用最新实际持仓计算差额。旧管理范围通过前次计划承接。
- 资金不足、规格未核实、状态过时等会输出诊断。目标CSV和委托CSV显式标记 `BLOCKED`。
- 超高保证金/非正权益进入只减仓状态；不开新仓，也不默认强平无差额仓位。
- 发送前持久化、账户串行锁、未知或尚未核对的失败回报阻断后续发送。

## 500万元是否足够

**当前样本不能满足全部非零品种至少一手。**

口径：唯一正式策略“多源韧衡(18)”、排名缓冲1、经核对的空仓冷启动；
当前本地认证行情最新完整日为 **2026-09-11**。38个品种中20个非零目标；
按500万元基准权益和原权重折算，17个能取整至至少一手。

| 未达到一手的品种 | 实际合约 | 原始目标手数 | 四舍五入后 |
|---|---|---:|---:|
| 股指IF | IF2612 | -0.2751 | 0 |
| 二年国债TS | TS2612 | -0.4875 | 0 |
| 原油SC | SC2610 | +0.1830 | 0 |

本截面各品种四舍五入后至少一手的权益门槛约 **1,366.01万元**；
按比例未取整前各品种完整达到一手约 **2,732.01万元**，均由SC约束决定。
它们仅是本截面的数量门槛，仍须另检保证金、净暴露和交易限制，并非增资建议。

取整后总名义金额876.36万元、净多134.32万元，净暴露为权益的 **26.86%**，
超过案例配置的10%上限。静态参考保证金约38.95万元，不能代表Panda当日账户保证金。
因此不能因“参考保证金够用”就判定整个正式组合可开仓，也不能强制把三个0手改成1手。

## 当前验收边界

1. 未执行真实订单；paper测试是理想数量成交，不代表成交速度、滑点或收益。
2. Panda当前空仓。非空持仓字段和今昨仓映射尚无真实样本验证；缺映射会明确拒绝，
   上期所/能源中心今昨平仓不能默认为已自动适配。
3. 实际委托前必须提供核实的当日合约规格、最新完整收盘信号、最新资金与持仓。
4. 带缓冲的多策略净额账户需提供经核对的逐实例状态；真实净额不能自动反推出各策略持仓。
5. 当前只接已核对的中性组合目录。并行开发的只做多扩展尚不在本次交易验收范围内。
6. `config/trading.local.yaml` 与所有账户运行证据仅保留本机；配置已被Git忽略，执行开关关闭。
7. 只减仓表示仅允许平仓指令；实际释放多少保证金以柜台为准，首版不模拟组合保证金优惠。

不能把物理吨数5直接当作价格点乘数。对应单位计算测试已加入。
