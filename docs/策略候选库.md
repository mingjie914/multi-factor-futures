## 保存与使用

- 无参数执行 `run_portfolio_workflow.py`：默认 `RUN_PREFERRED`，运行多源稳衡。
- 比较八组：将 `WORKFLOW` 设为 `RUN_AND_COMPARE`，`STRATEGY_IDS=()`。
- 指定一组或几组：在 `STRATEGY_IDS` 填下表稳定 ID。
- 只检查配置：`VALIDATE_CONFIGURATIONS`；显式比较其他模型方法：
  `RUN_AND_COMPARE_CONFIGURED`。生产方法观察不自动换成 Ridge 或分周期袖套。
- `RUN_AND_COMPARE_ALL` 也遵循非归档目录，不重新引入旧6因子。
- 旧6仅保留 `snapshot_6f_icir` 归档，可通过快照审计分支显式复核。

五组新候选的成员仅保存在目录 `factor_sets`，共享 `config/default.yaml` 的方法参数，
运行时绑定成员，不复制五份方法 YAML；冻结方向与当前有效库不一致时拒绝静默切换。
旧8/10/13引用版本控制内的 `config/factor_sets/legacy_*f.json` 冻结成员和方向，
走 `legacy_observation` 通道；归档6同样保存定义，不依赖本机未提交的完整快照。
`strategies/combined.py` 与 `config/default.yaml` 内的旧10定义仍是历史兼容基线，

近似有效维数是相关矩阵特征值参与率：`d_eff = (Σλ)² / Σ(λ²)`。
本次使用带符号的因子暴露相关矩阵；成对缺失处理可能使矩阵非半正定，
因此负特征值截零，称为“近似”。它不是熵有效秩。

17个完全重复（包括符号相反）的因子约为1维；17个线性不相关因子为17维。
多源稳衡的13.74表示其线性信息分散程度相当于约13.74个等强度方向，
不代表13.74个统计独立、有效或盈利的因子。相同因子数和样本下，较高表示较少冗余；
不同规模可辅助看 `d_eff / 因子数`。它不是越高越好：独立噪声也能增加维数。
应结合净收益、分阶段稳定性、回撤与成本判断，不作为额外准入门槛或单项排名目标。

逐因子类别、簇号、注册输入bar标签、当前准入状态见
`runs/factor_selection/20260909_eight_strategy_review/factor_classification.csv`。
注册输入标签不代表每项内部依赖都是同一bar；例如板块宽度使用日频子依赖。
所有组合仍日频更新，best_period只是准入证据标签，不用于机械设定持仓天数。

## 各组简评

1. **多源稳衡**：期限、形态、量价、冲击、板块五类较均衡；正负方向8/9，
   平均绝对暴露相关约0.077，17因子覆盖16簇。五个历史阶段均正收益，
   最差阶段夏普0.81、滚动252日正收益比例91.1%。默认强调稳定和回撤，因此首选。
2. **期限共振**：期限结构增加至6项，并加入席位信息，收益与费用承受力更强；
   但最差阶段夏普0.77、滚动252日正收益比例80.9%，回撤高于多源稳衡。
   作为偏收益的首要替代，不必与默认组合二选一删除。
3. **冲击增强**：在期限共振上增加波动冲击信息；全期收益略高，但最大回撤15.70%，
   最差历史阶段夏普0.61。与期限共振日收益相关约0.897，二者并非高度独立的两份配置。
4. **持仓趋势**：期限与形态为主，加入席位、没有板块宽度；13因子覆盖13簇。
   结构较紧凑，近期观察较好，但历史阶段中位夏普约0.81，不能仅凭近期表现升为默认。
5. **精简多源**：10因子覆盖10簇、近似有效维数9.08，正负方向5/5。
   覆盖类型少于多源稳衡，历史滚动252日正收益比例75.7%；适合作为精简备选。
   81日模拟观察表现最好，但没有以这段结果反向决定默认组合。
6. **量价趋势**：旧8，侧重量价与趋势形态，缺少多项期限/板块/席位信息。
   五阶段中最弱阶段夏普约0；只有2项属于当前有效库，保持历史观察，不作为当前默认。
7. **量价脉冲**：旧10，量价流动性5项，近似有效维数约7.21，信号来源较集中。
   长期回撤23.24%，当前准入成员4项，保留作不同风格参照。
8. **量价持仓**：旧13，在量价与冲击上增加席位；旧组中回撤相对较小（12.04%）。
   与多源稳衡收益相关约0.382，具有风格差异，但收益和费用承受力仍偏弱，暂不替代默认。
