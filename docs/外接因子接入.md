
## 使用顺序

```powershell
$PY = 'E:\Python\Pythonvenv\Scripts\python.exe'
& $PY -X utf8 -B -m workflows.external_factor_admission prepare --study external_daily_study
& $PY -X utf8 -B -m workflows.external_factor_admission profile --study external_daily_study
& $PY -X utf8 -B -m workflows.external_factor_admission validate --study external_daily_study
# 审阅正式结果后，显式生成扩展研究库；不会写默认库
& $PY -X utf8 -B -m workflows.external_factor_admission admit --study external_daily_study
# 可选：从扩展库调用现有组合搜索，不覆盖当前8组候选
& $PY -X utf8 -B -m workflows.external_factor_admission select --study external_daily_study
```

`prepare`冻结所有非intraday候选、原公式/参数、频率/预测期和受保护文件哈希。
`profile`不计算未来收益，仅检查全准入窗口的可计算性、横截面变化、截断输入后的
历史前缀一致性并记录性能。前缀检查是必要的机械检查，不等同于完整的无泄露证明。
机械无效者与统计未通过者分开报告。未明确适配的输入不填造、缺失不补零。
`validate`将全部机械合格者作为一个新增批次交给原正式检验，一起做层级FDR，
不会按64因子的计算批次分别准入。范围/适配代码/数据发生变化须新建study。

## 不改变原定义的适配

- 原因子保持原名称与实现；别名为 `external_daily__<原名称>`，仅在显式操作期间注册。
- 原生日频复用原compute，保留已有方向和滞后，不再次平滑或shift。
- 季节性等长历史公式仅扩展外接计算的数据读取范围，输出仍裁切到原请求日期；
  统计准入起点、统一预热参数不变，额外读取范围纳入外接数据指纹。
- 分钟SPEC复用已存在的交易日归属、日末聚合及滞后路径；声明输出daily、保留原始bar标签。
  新日频定义在运行前冻结预测交易日数，不继承原分钟检验的通过身份。
- SPEC别名仅临时加入原批量索引，继续共享base/transform计算；退出（包括异常）清除别名。
- 依赖股票市值/行业而无期货对应数据的公式标为未接入，不构造替代输入。
- GP不扫描测试SQLite、不自动挖掘。未提供真实冻结快照时不纳入；已训练候选需独立审核
  训练区间、方向、滞后和检验独立性，不因接入到日频而自动具备正式准入资格。

验收终点是“候选可重算、输入和时序明确、同门槛证据可追溯”，不是保证找出有效GP因子。

### 恢复候选日频接入入口

入口为 `python -m factor_mining.daily`，仅显式调用时启用；原分钟快照、GP CLI和主流程不变。
按顺序使用以下命令，研究ID必须是新的，不能覆写旧合同：

```powershell
$PY = 'E:\Python\Pythonvenv\Scripts\python.exe'
& $PY -X utf8 -B -m factor_mining.daily prepare --study recovered_gp_daily_study
& $PY -X utf8 -B -m factor_mining.daily profile --study recovered_gp_daily_study
& $PY -X utf8 -B -m factor_mining.daily validate --study recovered_gp_daily_study
# 审阅后，将通过者追加到该研究目录的隔离扩展库，不写默认154条库：
& $PY -X utf8 -B -m factor_mining.daily admit --study recovered_gp_daily_study
```

`prepare`读取恢复目录全部SQLite并验证候选，冻结原表达式、原训练区间、当前38品种、
H5/H10/H20日频检验族、关键配置/源码哈希和覆盖训练期的数据指纹。旧快照不补字段、不重写。
`profile`共用真实分钟数据、特征及表达式缓存；原分钟预处理、原分钟方向与两项既有bar滞后
保留。交易日末按各品种最后有报价的bar取值，不向前跳过末bar的NaN信号；不再额外日移位。
夜盘归属复用数据源交易日映射，不按自然日期猜测。日频方向调整只使用各候选原训练起点
至2022年底的日频训练IC（H5/H10/H20均值符号），再乘一次；正式检验预声明期望方向为正。
这与原分钟方向是两个明确阶段，不是在正式准入期看到负IC后再次翻转。

缺字段、旧分组标签不覆盖当前品种、前缀不一致或训练方向不可定义者均记录失败原因。
原样本量门槛仍由正式检验模块执行，不能将分钟bar数量冒充日频训练天数。
`validate`统一调用原正式准入；`admit`调用原库模块，仅原子发布研究目录内扩展库。
退出时清理临时注册名及方向映射，默认因子注册不增添GP成员。

共享计算只是分钟桥接器的可选参数；未提供参数时继续原实现。接入回归覆盖原/共享计算
一致性、夜盘归属、末bar缺失保留及异常注册清理。批量真实数据已与原逐个计算对照。
此入口负责旧候选日频适配，不等于已完成或启动新的日频GP挖掘。

### GP性能边界

GP的显式`fast`滚动路径（原CLI的`--use-fast-rolling`）使用Polars的Rust内核计算最小值和最大值；均值继续Bottleneck，
标准差、中位数等保留参考实现，未将整个GP宣称为Rust重写。原默认`pandas`路径、
GP搜索参数与主框架配置不变。回归直接验证Rust输出（不能靠回退掩盖差异），覆盖
NaN、无穷值、零方差和窗口长于输入；检查数值、缺失位置以及真实表达式最终输出。
日末取值的位置索引按行情组计算一次，各候选共享，仍保留末bar缺失信号。
每组记录读取、特征构建及总耗时，阶段记录墙钟、CPU及采样峰值RSS。
固定2022年第四季度、38品种的409候选对照中，364个可计算候选的最终日频输出逐值相等，
另45个因原分组标签不覆盖当前品种在两路径均失败；证据为
`runs/factor_research/20260910_recovered_gp_daily_v2/polars_rust_check.json`。
这是固定季度的全公式对照，不冒充全历史或正式检验结论的双跑验证。

`20260910_recovered_gp_daily_v1`在生成训练收益时停止，未产生正式准入结论：
它误将2015年计算预热也纳入训练标签检查，遇到SN的未批准行情缺口。
后续版本先检查实际训练区间（最早2016-01-04，截止2022年底），只让预热服务于特征计算；
不缩短任一候选训练期、不批准缺失事件，也不放宽原行情质量门槛。旧合同保留为失败证据。

## 13个普通分钟结构因子的改写与正式检验（2026-09-10）

本批已作为普通类直接注册在 `factors/library/intraday.py`，注释编号589—601、
登记顺序611—623。模块现有623个因子：618个分钟输入、5个日线输入。
