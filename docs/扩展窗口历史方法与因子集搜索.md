# 扩展窗口历史方法与因子集搜索

## 1. 目标与边界

本工作流在当前有效因子库固定不变的前提下，寻找更合适的因子集、因子信号合成、
Top/Bottom 选池和池内品种权重。它不尝试重建因子过去的研发时间，也不修改生产策略。

历史研究使用四个扩展窗口：

| 折 | 训练期 | 测试期 |
|---|---|---|
| fold_1 | 2016-03-31~2019-12-31 | 2020-01-01~2021-12-31 |
| fold_2 | 2016-03-31~2021-12-31 | 2022-01-01~2023-12-31 |
| fold_3 | 2016-03-31~2023-12-31 | 2024-01-01~2024-12-31 |
| fold_4 | 2016-03-31~2024-12-31 | 2025-01-01~2026-08-06 |

测试期不参与该折的统计、聚类、方法选择或因子选择。最终评价以四段测试收益拼接后的
净值为准。由于当前因子公式可能源于完整历史研究，结果属于严格时序的反事实研究，
不能等同于真实历史实盘。

## 2. 固定条件

- 当前 74 个有效因子候选池；
- 38 品种母池，未上市或历史不足品种按 T-1 风险历史自动过滤；
- 60 日因子权重历史，严格排除 `IC[T]`；
- ERC/逆波动风险历史严格排除 T 日收益；
- 多空两侧各归一化为 1，总敞口 2；
- 日度调仓，交易成本 0.02%，年费 0.1%；
- 相同连续合约和换月数据口径。

## 3. 方法搜索

为避免 `4×3×2×3` 全笛卡尔积与因子搜索相乘，使用三阶段坐标消融：

1. 固定 Top10/Bottom10、cap3、ERC，比较因子等权、正向 ICIR（均值/标准差）、当前 LW 后取绝对值、
   LW 求解后非负截断并设置 35% 上限；
2. 保留前两种因子合成，比较 Top/Bottom 8、10、12，以及 cap3/无 cap；
3. 保留前两种选池，比较等权、逆波动率和收缩 ERC，最终保留每折前三名供因子集交互验证。

上述三步在每个扩展窗口内独立完成；早期折不会使用后期折的入围方法并集。每个候选
也只计算该折训练区间，胜出方案才计算下一段测试权重。

每个阶段在 6f、14f、R8 三个结构不同的种子因子集上共同评价，按以下固定次序排序：

1. 正夏普训练分段比例；
2. 最差分段夏普；
3. 分段夏普中位数；
4. 分段年化收益中位数；
5. 最差回撤。

该规则优先稳定性，不直接最大化全期终值。

## 4. 因子集搜索

每个训练窗口独立完成：

1. 按覆盖率、方向化平均 IC 和分段方向一致性过滤；
2. 使用训练期日度 IC 序列绝对相关性做 complete-linkage 聚类，阈值 0.65；
3. 每簇最多一个因子，搜索因子数 4~12；
4. 使用宽度 20 的窄束搜索，按最差/中位分段 IC 夏普保留路径；
5. 将前 12 条路径与必要的 6f/10f/13f/14f/R8 基线一起，用该折前三名组合方法做精确扣费回测；
6. 仅根据训练期稳健性选出该折方案，冻结到下一测试期。

该流程不固定保留生产6f，也不沿用旧实验“最多增加8个”的锚定规则。4~12的范围是
当前有限计算预算下的预声明搜索区间：下限避免过少因子高度偶然，上限控制IC协方差
维度、换手和组合搜索数量；它仍不是理论上的最优因子数。若边界候选持续胜出，应在
下一轮预先扩大边界，而不是事后追加因子。

旧13f来自“生产6f为起点、最多前向增加8个”的历史探索，再从14f中去掉
`ma_count_bullish`。固定6f是当时的保守锚定，8步是工程上限，均不构成最优性证明；
因此13f在本工作流中只作为已知固定基线参与比较。

R8 的替代方法只与生产方法组成一个预声明的两方案挑战：每折在训练期按相同稳健性
规则选择，冻结到下一测试期。命令如下：

```powershell
& 'E:\Python\Pythonvenv\Scripts\python.exe' -X utf8 -B `
  -m workflows.experiments.historical_portfolio_search `
  --r8-recipe-only --output runs/historical_portfolio_search/<run_id>
```

该机制消除了测试期参与当折选择，但替代方法本身源于已有历史观察，仍需未来影子期
才能获得真正独立的生产证据。

2026-08-11 的冻结验证中，替代方法在四折训练期均排名第一，因此四段测试全部冻结为
`因子等权 + Top12/Bottom12 + 无板块cap + 逆波动率`。2020-01-02~2026-08-06
拼接结果为年化30.95%、夏普2.59、最大回撤-10.40%；R8生产方法同期为15.64%、
1.33、-16.88%。运行证据位于
`runs/historical_portfolio_search/20260813_contract_symbol_fix/`。郑商所合约代码修正后
重新运行的逐折选择及替代方法结果完全不变；生产方法基线夏普由1.3345小幅变为1.3324。

该结果说明替代方法并非只由最后一折驱动，但仍不能消除“方法假设源自全历史观察”的
研究者自由度。当前结论是进入影子候选，而不是自动修改生产。

最终还会报告相邻折因子集 Jaccard、双倍交易成本压力结果以及固定方案对照。

## 5. 运行与产物


- `adaptive_oos_weights.csv` / `adaptive_oos_ledger.csv`：拼接滚动样本外账本；
- `comparison_metrics.csv` / `nav_comparison.csv` / `nav_adaptive_oos_comparison.png` / `REVIEW.md`：最终结论；
- `focused_candidate_metrics.csv` / `nav_recommended_combinations.png`：少量合理候选的聚焦对比。

## 6. 2026-08-10 完整研究结论

保留运行目录为 `runs/historical_portfolio_search/20260810_full_prod_sort/`。该目录的
训练期方法排序、因子聚类和逐折选择仍是当前决策证据；其下述拼接末期指标生成于
郑商所日线清理前，只作为当时研究记录，不作为当前固定方案净值。当前固定方案指标见
`runs/external_guosen_trend_index/20260813_contract_symbol_fix/`。在 2020-01-02
至 2026-08-06 的四段冻结测试期拼接结果中，扩展窗口方案年化收益 19.26%、夏普 1.53、
最大回撤 -16.40%；双倍交易成本压力下夏普 1.20。同期固定 R8 为 15.67% / 1.33 /
-16.88%，固定 13f 为 12.62% / 1.23 / -13.72%。

当前生产方法 `LW绝对值 + Top10/Bottom10 + cap3 + ERC` 在四折方法搜索中均未成为
第一名，也未进入各折最终前三名。各折更常入围的是正向 ICIR 或非负 LW、Top8、无 cap，
池内逆波动率和 ERC 均有胜出，说明不存在一个在所有时期都占优的单一环节组合。

聚焦图中的 `R8_alt_method_retrospective` 使用完整结果后才选定的等权因子、Top12、无 cap、
逆波动率组合，仅用于说明方法选择的潜力，不是扩展窗口样本外证据。当前可进入影子观察的是
扩展窗口方案和结构更简单的固定 R8；13f 可作为低回撤参照，均不自动替代生产。
