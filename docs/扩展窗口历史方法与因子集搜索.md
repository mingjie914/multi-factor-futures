# 扩展窗口历史方法与因子集搜索

> **2026-08-17状态**：底层代码、本地Parquet和统一组合账本门禁已通过；固定8f/10f/13f
> 已重建。修复前的搜索排名和逐折选择仍不作为证据。本文保留预声明方法，后续搜索必须从
> 审计通过后的因子面板重建，不能把旧选择当成先验最优方案。

## 1. 目标与边界

本工作流在当前有效因子库固定不变的前提下，寻找更合适的因子集、因子信号合成、
Top/Bottom 选池和池内品种权重。它不尝试重建因子过去的研发时间，也不修改生产策略。

历史研究使用四个扩展窗口：

| 折 | 训练期 | 测试期 |
|---|---|---|
| fold_1 | 2016-03-31~2019-12-31 | 2020-01-01~2021-12-31 |
| fold_2 | 2016-03-31~2021-12-31 | 2022-01-01~2023-12-31 |
| fold_3 | 2016-03-31~2023-12-31 | 2024-01-01~2024-12-31 |
| fold_4 | 2016-03-31~2024-12-31 | 2025-01-01~2026-08-06 |

测试期不参与该折的统计、聚类、方法选择或因子选择。最终评价以四段测试收益拼接后的
净值为准。由于当前因子公式可能源于完整历史研究，结果属于严格时序的反事实研究，
不能等同于当时已知信息下开发并由外部执行的真实实盘。

## 2. 固定条件

- 当前 74 个有效因子候选池；
- 38 品种母池，未上市或历史不足品种按 T-1 风险历史自动过滤；
- 60 条因子权重历史，先严格排除 `IC[T]` 再取窗；
- ERC/逆波动风险历史严格排除 T 日收益；
- 分钟合约按完整字母根精确匹配，连续合约按上一交易日可观察映射选约；
- 正式结构的资产上下限在最终归一化后仍成立；
- 多空两侧各归一化为 1，总敞口 2；
- 收盘决策 `W[T]` 获得 `R[T+1]`，换手基于收益后漂移权重并显式计入移仓；
- 日度调仓，完整成交名义成本0.02%，管理费0，总暴露按年化0.105%摊销移仓成本；
- 相同连续合约和换月数据口径。

## 3. 方法搜索

为避免 `4×3×2×3` 全笛卡尔积与因子搜索相乘，使用三阶段坐标消融：

1. 固定 Top10/Bottom10、cap3、ERC，比较因子等权、正向 ICIR（均值/标准差）、当前 LW 后取绝对值、
   LW 求解后非负截断并设置 35% 上限；
2. 保留前两种因子合成，比较 Top/Bottom 8、10、12，以及 cap3/无 cap；
3. 保留前两种选池，比较等权、逆波动率和收缩 ERC，最终保留每折前三名供因子集交互验证。

上述三步在每个扩展窗口内独立完成；早期折不会使用后期折的入围方法并集。每个候选
也只计算该折训练区间，胜出方案才计算下一段测试权重。

每个阶段在 6f、14f、8f 三个结构不同的种子因子集上共同评价，按以下固定次序排序：

1. 正夏普训练分段比例；
2. 最差分段夏普；
3. 分段夏普中位数；
4. 分段年化收益中位数；
5. 最差回撤。

该规则优先稳定性，不直接最大化全期终值。

## 4. 因子集搜索

每个训练窗口独立完成：

1. 按覆盖率、方向化平均 IC 和分段方向一致性过滤；
2. 使用训练期日度 IC 序列绝对相关性做 complete-linkage 聚类，阈值 0.65；
3. 每簇最多一个因子，搜索因子数 4~12；
4. 使用宽度 20 的窄束搜索，按最差/中位分段 IC 夏普保留路径；
5. 将前 12 条路径与必要的 6f/10f/13f/14f/8f 基线一起，用该折前三名组合方法做精确扣费回测；
6. 仅根据训练期稳健性选出该折方案，冻结到下一测试期。

该流程不固定保留生产6f，也不沿用旧实验“最多增加8个”的锚定规则。4~12的范围是
当前有限计算预算下的预声明搜索区间：下限避免过少因子高度偶然，上限控制IC协方差
维度、换手和组合搜索数量；它仍不是理论上的最优因子数。若边界候选持续胜出，应在
下一轮预先扩大边界，而不是事后追加因子。

旧13f来自“生产6f为起点、最多前向增加8个”的历史探索，再从14f中去掉
`ma_count_bullish`。固定6f是当时的保守锚定，8步是工程上限，均不构成最优性证明；
因此13f在本工作流中只作为已知固定基线参与比较。

8f 的替代方法只与生产方法组成一个预声明的两方案挑战：每折在训练期按相同稳健性
规则选择，冻结到下一测试期。命令如下：

```powershell
& 'E:\Python\Pythonvenv\Scripts\python.exe' -X utf8 -B `
  -m workflows.experiments.historical_portfolio_search `
  --8f-recipe-only --output runs/historical_portfolio_search/<run_id>
```

该机制消除了测试期参与当折选择，但替代方法本身源于已有历史观察，仍需未来影子期
才能获得真正独立的生产证据。

修复前曾选出“因子等权 + Top12/Bottom12 + 无板块cap + 逆波动率”，但该选择使用了
受前缀污染的分钟因子，逐折结论已经失效。修复后只对固定8f/10f/13f做了重新评估和
Top10/12/14、60/90/120日邻域检查；这不等于重新完成逐折方法搜索。

最终还会报告相邻折因子集 Jaccard、双倍交易成本压力结果以及固定方案对照。

## 5. 运行与产物

```powershell
& 'E:\Python\Pythonvenv\Scripts\python.exe' -X utf8 -B `
  -m workflows.experiments.historical_portfolio_search `
  --output runs/historical_portfolio_search/<run_id>
```

若因数据读取或进程中断，可对同一输出目录使用 `--resume --output <目录>`；临时因子
面板缓存只用于恢复，中间文件会在成功完成后删除。

输出位于 `runs/historical_portfolio_search/<timestamp>/`，核心文件包括：

- `resolved_search_config.json`：冻结研究边界；

- `factor_training_diagnostics.csv` / `factor_clusters.csv`：各折训练期因子证据；
- `factor_candidate_results.csv` / `fold_decisions.json`：候选与逐折选择；
- `adaptive_oos_weights.csv` / `adaptive_oos_ledger.csv`：拼接滚动样本外账本；
- `comparison_metrics.csv` / `nav_comparison.csv` / `nav_adaptive_oos_comparison.png` / `REVIEW.md`：最终结论；
- `focused_candidate_metrics.csv` / `nav_recommended_combinations.png`：少量合理候选的聚焦对比。

## 6. 2026-08-17固定集合重评估

当前统一引擎重评估中，固定8f/10f/13f在生产结构下的长期夏普为
0.517/0.544/-0.029；替代结构为0.639/0.666/0.201。2025年以来生产结构夏普为
2.239/0.831/0.490，替代结构为0.371/0.437/-0.586，说明方法优劣存在明显区间依赖。
8f替代结构平均最大单品种占单侧45.6%、95分位71.6%，集中度不支持生产替代。

这些固定集合记录仍没有回答当前有效因子池中的最优因子集或最优方法。下一次扩展窗口搜索
必须使用审计后的因子面板和共享组合评估器；旧目录与旧逐折决定不参与初始化、短名单或参数选择。
统一证据位于`runs/external_guosen_trend_index/20260817_correctness_rebuild/`。
