## 对比基准用法

主框架探索其他组合时, 与本分支对比:
1. 同窗口 (2025-01~2026-07) / 同口径 (T-1信号×T日收益, 杠杆2.0)
2. 对比全段夏普 (本分支 2.04) / OOS (1.33) / 实盘 (-0.33) / 回撤 (-5.9%)
3. 新组合若全段+OOS 均优于本分支且实盘为正, 才可考虑替代

## 独立运行

本分支文件为快照, 不依赖主框架后续改动:
- 因子定义在 `factors/library/intraday.py` (主框架, 若该文件被改, 需重新导出权重)
- 权重已冻结在 `weights_daily.csv`, 可直接用于外部回测
