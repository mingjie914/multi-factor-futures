## 二、信号合成办法

### 2.1 因子预处理
- 每个因子按日计算, 已内建 `shift(1)` (T日信号只用 ≤T-1 数据, 无未来函数)
- 截面排名: `rank(pct=True)` → 每个品种在 T 日的相对排名 [0,1]
- 方向调整: 负向因子取 `1 − rank` (方向统一为正)

### 2.2 因子权重（IC_IR 动态加权）
- 滚动窗口 60 个交易日
- 每期计算各因子与未来收益的 IC (Spearman, 截面相关): `IC_n = corr(rank_n, fwd_rank)`
- Ledoit-Wolf 收缩协方差: `Σ_shrink = λ·F + (1−λ)·S` (F=目标矩阵, S=样本协方差)
- 最优权重: `w* = Σ⁻¹·mean(IC)`, 再取绝对值并归一化 `Σ|w|=1`
- **动态性**: 每 60 日窗口重新估计, 权重随因子近期 IC 表现漂移

### 2.3 合成得分
```
score_i = Σ_n w_n · rank_n(i)     (品种 i 的加权排名得分)
score = score / Σ(score)          (截面归一化)
```

## 三、选池与权重分配

### 3.1 板块配额选池 (cap=3)
- 全市场 38 品种按得分排序
- **每板块最多 3 个**多头(最高分) + 3 个空头(最低分)
- 板块映射: 有色/黑色/能化/农产品/金融 (5 板块)
- 选池结果: 10 多 + 10 空 (每板块 ≤3)

### 3.2 池内权重
- 多头池/空头池分别做 **ERC (等风险贡献)**: 使各持仓对组合风险贡献相等
- ERC 用过去 60 日收益协方差 (Ledoit-Wolf 收缩 λ=0.3), SLSQP 求解
- 约束: 单品种权重 [0.02, 0.5], 池内 Σw=1

### 3.3 杠杆与方向
- 多头: +1.0 (满杠杆多头) / 空头: -1.0 (满杠杆空头)
- **1倍杠杆版 (half)**: 多空各 0.5, 总风险暴露 1.0
- 日度调仓 (信号 T 日 → T+1 执行)
