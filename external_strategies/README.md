# 外部策略适配层

本目录用于复现或近似复现外部策略，并用项目现有数据与因子进行对照实验。
它是**单向依赖**：适配层可以调用框架的数据和因子接口，框架、生产策略、主配置和
交易批准门均不导入这里的代码。

每个外部策略放在独立子目录中，并包含：

- `config.yaml`：来源规则、明确参数、未披露参数的透明假设和可试验因子集；
- `strategy.py`：不修改框架的策略实现；
- 独立运行入口与测试；
- 运行产物写入 `runs/external_<strategy>/<timestamp>/`，不会覆盖生产结果。

当前变种：B1 `guosen_trend_index`（国信中国资产趋势配置指数形式）。
