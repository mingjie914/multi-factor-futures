# 国信趋势配置指数形式适配器

该适配器根据两份指数编制说明实现以下公开规则：九品种资产池、仅做多、每日调仓、
每个“因子 × 参数”将因子值保留 10 位小数后独立选出前 51%（九选五）、
目标波动率/相关性修正的逆波动
权重；先平均同一因子的多组参数权重，再平均不同因子权重，最后应用品种上限、
0.02% 交易成本和年化 0.1% 费用。

与项目生产策略的主要差异是：

- 资产池固定为 `AU, CU, IF, IC, RB, SC, M, TF, T`；
- 只做多，不构建空头组合；
- 每个因子独立形成组合后等权平均，不使用 IC_IR 合成；
- 使用文档给出的相关性修正逆波动公式，不使用生产策略的池内 ERC；
- 最终按资产类别限制单品种权重。

局限：文档没有披露原指数的因子、因子参数、波动率/相关性窗口和相关倍数上限；
目标波动率已由用户确认为 **4%**。所以这里是可审计的**形式代理**，不是对
`GSIXTREND.WI` 的精确复刻。
所有假设均在 `config.yaml` 中，可为新快照复制该文件后调整，无需修改框架主配置。
当前项目因子名称已经包含固定参数（例如 `_20d`），所以每个因子组暂时只有一个参数
版本；策略接口仍保留“因子内参数均值”这一步，增加参数版本时不会改变合成层级。

日期语义：项目因子输出已内建 `shift(1)`，因此 `factor[T]` 只使用不晚于 T-1 的
信息，并直接对应 T 日持有；配置中的 `execution_lag_days` 默认为 0，避免重复滞后。
若接入未经预滞后的外部原始因子快照，应将其改为 1。

运行示例：

```powershell
& 'E:\Python\Pythonvenv\Scripts\python.exe' -B -m external_strategies.guosen_trend_index.run `
  --start 2016-03-31 --end 2026-08-06 `
  --factor-set 6f --factor-set 10f --factor-set 13f --factor-set 14f `
  --equal-gross 1.0 --search-subsets
```

结果写入独立时间戳目录，不会覆盖生产净值或权重。

运行器会在回测起日前预取历史数据，避免基日后的风险窗口空仓；输出仍从指定基日
以 1000 点开始。`summary.json` 同时记录最终合成组合的九品种覆盖率。这里不通过
补仓强行制造全覆盖：若某个替换因子集不能让 9 个品种都被至少一个子组合选中，
该因子集会被标记为不满足原指数的实际持仓特征。配置中的参考净值只用于同期业绩
与相关性对照，不参与参数拟合或权重计算。

运行器会分别保存两种口径：

- `native_target_vol_4pct`：严格使用 4% 目标波动率公式和品种上限，不额外约束总权重；
- `equal_gross_1`：在不增加未入选品种、不突破品种上限的前提下，将每日多头总权重
  投影为严格 1 倍，用于与用户估计为约 1 倍杠杆的实际指数作同杠杆比较。

目标波动率与杠杆不是同一概念。风险预算公式在低波动时期可能产生超过 1 的总权重，
因此不能用简单的“目标波动率=4%”替代总敞口检查。每种口径均输出 2016-03-31 起和
2020 年起的净值图；指标包括年化收益、年化波动、夏普和最大回撤。

`--search-subsets` 会复用一次计算得到的单因子组合，穷举当前 14 因子池的 16,383 个
非空子集。排序只使用 2016-2019、2020-2022、2023-2024 三个开发分段，2025 年以后
仅作为留出诊断，不进入开发分数。该结果用于提出后续候选，不等同于生产准入结论。

本地原始 `SC*`、`SC8888` 和框架连续合约的首个有效日均为 `2018-03-26`。因此
2016-03-31 至 SC 上市前不可能构造九品种真实持仓；适配器让 SC 自然缺席，不通过
代理品种或后见回填伪造上市前历史。
